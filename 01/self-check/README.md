# SQL для самопроверки

Используйте эти файлы после самостоятельного выполнения. Пояснения и ожидаемые результаты находятся в [ключе](../answer-key.md).

- [schema.sql](schema.sql) — полная схема; применяется только к отдельной пустой базе.
- [queries.sql](queries.sql) — решения трёх SELECT; выполняются на схеме с готовым seed.
- [invalid-writes.sql](invalid-writes.sql) — три некорректные вставки; выполняются отдельно в autocommit и вызывают ожидаемые отказы.

Сравнивайте результат и выраженные правила; имена ограничений и оформление SQL могут отличаться.
