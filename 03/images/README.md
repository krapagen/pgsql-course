# Образ для стенда домашнего задания 3

Compose использует postgres:18.4-alpine. Образ не включён в папку материалов, чтобы пакет оставался небольшим. Если образ ещё не загружен, Docker получит его при первом запуске; для этого нужен интернет.

Для занятия без доступа к интернету заранее выполните:

```sh
docker pull postgres:18.4-alpine
docker save -o postgres-18.4-alpine.tar postgres:18.4-alpine
```

Передайте tar отдельно и на компьютере студента выполните:

```sh
docker load -i postgres-18.4-alpine.tar
```

Архитектура образа должна подходить компьютеру получателя. Сам пакет SQL и Markdown не зависит от ARM64/AMD64. Версию сервера фиксируйте по SELECT version(), а не только по имени образа.
