# SQL для самопроверки пяти запросов

Файл [queries.sql](queries.sql) содержит пять готовых решений; файлы 01.sql ... 05.sql — те же решения по отдельности. Открывайте после самостоятельной попытки. Сам факт совпадения SQL не является целью: важны сохранённый результат и объяснение устранённой работы.

Для чтения решений откройте queries.sql. Для выполнения подключитесь к psql по [README пакета](../README.md), примените `\i /work/settings.sql` и выполняйте SELECT по одному. `\i /work/self-check/queries.sql` выведет результаты всех пяти задач; это самопроверка значений, а не полноценный протокол замеров. Для анализа планов добавляйте EXPLAIN перед отдельным запросом.

Для автоматической проверки по желанию, из терминала компьютера в папке пакета:

```sh
python3 tools/check.py --solutions self-check
python3 tools/measure.py --solutions self-check --runs 3
```

Это проверит эталонные файлы и сохранит их планы в results/. Команда measure заменяет одноимённые результаты предыдущего запуска; сначала скопируйте свои результаты, если они нужны для сдачи.

Решения не создают индексов и объектов схемы. Q1 использует одну агрегацию и LEFT JOIN; Q2 три EXISTS; Q3 убирает материализацию всей истории; Q4 группирует только позиции нужных заказов; Q5 выбирает последнюю строку после отбора нужных заказов. Для Q5 допустима и оконная версия на таком же сокращённом входе.
