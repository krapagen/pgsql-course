# Образ PostgreSQL

Стенд использует Docker-образ **postgres:18.4-alpine**, закреплённый в [compose.yaml](../compose.yaml). Дополнительных образов для задания не требуется: psql входит в образ PostgreSQL.

## Подготовить образ

В папке пакета выполните:

```sh
docker compose pull
```

Docker скачает подходящий образ для архитектуры компьютера. После этого стенд запускается через `docker compose up -d --wait`. Образ также загружается автоматически при первом запуске, если отсутствует локально.

Образ можно предварительно загрузить при наличии интернета и затем использовать локально. Для передачи сохранённого образа между компьютерами требуется экспорт для соответствующей платформы; образы ARM64 и AMD64 различаются.
